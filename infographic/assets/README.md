# Assets

`template.html` — the working skeleton. Copy it into the workspace and fill it in. It
carries the tokens, the three canvas presets, the type scale and every component
(illustrated stat tiles, split, band, bars, nodes). Do not rewrite the CSS from scratch.

Output goes to the **workspace**, never here:

```text
examples/infographics/<name>/
├── index.html
├── illustrations/
└── <name>.png
```
